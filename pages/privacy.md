This is a personal blog. I don't ask for your name or email, and there are no accounts, comments or contact forms.

The site is hosted on GitHub Pages. GitHub may log technical details such as your IP address when you visit, as described in the GitHub privacy statement. Fonts are loaded from Google Fonts, which means your browser connects to Google's servers.

If I add analytics or advertising in the future, this page will be updated first to explain what is collected and how you can opt out.
