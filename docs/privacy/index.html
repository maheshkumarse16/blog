Privacy

This is a personal blog. I don't ask for your name or email, and there are no accounts or contact forms.

The site is hosted on GitHub Pages. GitHub may log technical details such as your IP address when you visit, as described in the GitHub privacy statement. Fonts are loaded from Google Fonts, which means your browser connects to Google's servers.

Comments

Comments on posts use giscus, which stores them as GitHub Discussions in this site's public GitHub repository. To comment you sign in with your GitHub account, and your GitHub username, profile picture and comment are shown publicly. Comments are covered by the GitHub privacy statement. The comment box loads from giscus.app only when you scroll down to it. If you want a comment removed, reply to it or contact me through GitHub.

If I add analytics or advertising in the future, this page will be updated first to explain what is collected and how you can opt out.
