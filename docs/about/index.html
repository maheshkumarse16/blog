About

Hi, I'm Mahesh, a Senior End User Computing Architect.

I have spent a long career in enterprise IT, and I have seen Windows and the way we manage it change many times over, from on premises imaging and Configuration Manager to cloud native Intune and Windows 365. Along the way I have worked across almost every part of end user computing, from day to day operations to designing enterprise wide endpoint platforms as an Intune architect.

Today most of my time goes on Microsoft Intune, Windows 11 and Entra ID, with Configuration Manager still looking after plenty of devices alongside. I design and run the platforms that keep thousands of users productive and secure, from Cloud PCs and Azure Virtual Desktop to Defender, Purview and vulnerability management.

I started this blog to share what I learn each day. New features in Intune and ConfigMgr, Windows updates that break things, the fixes that actually work, what to do while you wait for Microsoft to ship a fix, and step by step guides for rolling out policies and migrations. If it helped me, there is a good chance it will help you too.

Everything here is my own view and not my employer's. Always test in your own environment before you change anything in production.
